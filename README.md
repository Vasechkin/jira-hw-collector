# Коллектор оборудования Jira

`jira-hw-collector` получает максимально полный снимок проекта учёта оборудования Jira: карточки оборудования со всеми стандартными и пользовательскими полями, справочник полей, историю изменений, комментарии, трудозатраты, связи, внешние ссылки, свойства, наблюдателей, голоса и метаданные вложений. По умолчанию содержимое вложений не загружается. Его загрузку можно включить отдельно только для целевого анализа.

Коллектор использует тот же локальный `config.toml` и `.env`, что и `jira-sdesk-collector`. Рабочие адреса, ключ проекта, JQL, прокси, токены, сертификаты и собранные данные не находятся в репозитории.

## Требования

- Python 3.11 или новее;
- персональный токен Jira с доступом на чтение проекта оборудования;
- `age`, если включено шифрование результатов;
- корпоративный сертификат удостоверяющего центра либо настроенный в локальной конфигурации диагностический режим TLS.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
```

## Общая конфигурация Jira

Добавьте секции `[hardware]`, `[hardware_output]` и `[hardware_archive]` из `config.toml.examole` в существующий локальный файл `jira-sdesk-collector/config.toml`. Секцию `[jira]` и файл `.env` дублировать не нужно.

В каталоге нового проекта можно создать локальную символическую ссылку:

```bash
ln -s ../jira-sdesk-collector/config.toml config.toml
```

Файл `config.toml` исключён из Git. Токен читается из переменной, заданной параметром `token_env` общей секции `[jira]`.

## Команды

Проверка локальной конфигурации без обращения к Jira:

```bash
jira-hw-collector --config config.toml validate
```

Проверка доступа, подсчёт объектов и доступных полей:

```bash
jira-hw-collector --config config.toml probe
```

Полный сбор:

```bash
jira-hw-collector --config config.toml collect
```

Целевая загрузка только явно выбранных вложений:

```bash
jira-hw-collector \
  --config config.toml \
  download-attachments \
  --selection-csv attachment-selection.csv
```

Файл выбора должен содержать колонки `key` и `filename` или `id`. Вложения, которых нет в CSV, не загружаются. Результат упаковывается и шифруется так же, как полный снимок.

## Результаты

В каждый снимок входят:

- `equipment.json` - полные ответы Jira по оборудованию и связанным объектам;
- `equipment.csv` - плоская таблица со стандартными и всеми обнаруженными пользовательскими полями;
- `field_catalog.csv` - соответствие идентификаторов полей их названиям и схемам;
- `issue_links.csv` - внутренние и внешние связи;
- `attachments.csv` - метаданные, контрольные суммы и результаты загрузки вложений;
- `changelog.csv` - нормализованная история изменений;
- `manifest.json` - состав, время, количество объектов и ошибки снимка.

Если шифрование включено, каталог упаковывается в `hardware-collection-archives/*.tar.gz.age`, создаётся SHA-256, а открытый каталог удаляется после успешного шифрования.

## Полнота и ограничения

Коллектор автоматически запрашивает `*all` и каталог полей Jira. Поэтому новые пользовательские поля появляются в JSON и CSV без изменения программы. Недоступные по правам дополнительные REST-ресурсы помечаются кодом ответа; при `best_effort = true` это не прерывает весь снимок.

Полнота определяется правами токена Jira. Коллектор ничего не изменяет в Jira.

## Сопоставление с другими инвентарями

Утилита `tools/compare_inventory.py` сопоставляет карточки Jira с результатами сетевого и OpenStack-коллекторов по серийному номеру, hostname и IP. Она формирует таблицы совпадений, отсутствующих объектов, повторяющихся идентификаторов и вложений, которые могут содержать дополнительные технические сведения.

## Безопасность

- каталоги результатов получают права 0700, файлы - 0600, используется `umask 077`;
- поля с именами `password`, `secret`, `token`, `community` и аналогичными маскируются;
- токен не записывается в результаты и журнал;
- вложения с внешнего домена не загружаются с авторизацией Jira;
- рабочая конфигурация, `.env`, ключи, сертификаты и результаты исключены из Git.
